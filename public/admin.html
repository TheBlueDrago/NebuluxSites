Nebulux Sites · Admin

Admin

Enter your admin key (the ADMIN_KEY secret on the Worker).

Update requests

From finished customers (their Monitor tab). Set a price (0 = free), then mark it done.

Reviews

From finished customers. Approved ones show on the homepage.

Waitlist

Emails people left on the "down for maintenance" page.

Promo codes

A percentage off a website's price. Customers type it on the Billing page (one code per order, 100% makes it free).
